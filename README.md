# Yut Multiplayer V3.1

사진 기반 윷판을 사용하는 윷놀이 멀티플레이 게임입니다.

## 반영된 규칙
- 사진 오른쪽 아래 노란색 원을 시작점으로 사용
- 말은 윷판을 **시계 반대방향**으로 이동
- 윷/모: 한 번 더 던지기
- 상대 말을 잡으면 한 번 더 던지기
- 업기: 자신의 말이 있는 칸에 도착하면 **업기 / 따로 이동** 선택
- 내 차례에 1~4번 중 원하는 말을 선택
- 말에 1, 2, 3, 4 번호 표시
- 내 말 남은 개수와 도착 개수 표시
- 모든 말 4개가 도착하면 승리
- **빽도**: 1칸 뒤로 이동
- 출발점(판 밖)에만 말이 있고 빽도가 나오면 해당 기회는 취소되고 다음 차례로 넘어감
- 판 위의 말이 있는 상태에서 빽도가 나오면 이동 가능한 말을 선택해 1칸 후퇴
- 코너에서 **직진 / 대각선** 이동 방향 선택

## Render 설정
- Type: Web Service
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 프로젝트 파일이 저장된 위치
